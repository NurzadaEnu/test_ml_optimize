# test_ml_optimize

ML-пайплайн для оптимизации режима реактора гидроочистки Р-1 (установка ЛГ-35-11/300-95) — версия после рецензирования. Суррогатные модели XGBoost по режимным параметрам x1–x5 предсказывают объём гидрогенизата и показатели качества, после чего решается единая задача оптимизации: максимум объёма при заданном уровне качества.

> ⚠️ Проект работает на **синтетических данных** — физически обоснованный суррогат установки. Модели наследуют его ограничения; перенос на реальную установку требует переобучения на заводских данных (временной сплит).

## Что изменено после рецензирования

| Замечание | Что сделано в коде |
|---|---|
| R1-1 | Объём: `y1 = x1·η(x2,x3)`, η откалибрована МНК по трём режимам таблицы 1 (76.0 / 77.5 / 77.0 м³/ч); η ≤ 0.995 ⇒ `y1 < x1` всегда |
| R2-6, R1-3 | μ1–μ3 — степени превращения из кинетики Аррениуса, откалиброванной в **центре** рабочих диапазонов. Функции не центрированы на решении AorRA+PO, генератор не содержит информации об оптимуме |
| R1-4, R2-4 | Единая задача (Eq. 16) с явным ограничением `y1 ≤ x1`; лексикографическая двухэтапная постановка удалена; фронт объём–качество (ε-constraint) |
| R1-5 | Все режимы таблицы 1 оцениваются на одной общей модели качества (`data/table1_common_model.csv`) |
| R1-2, R2-3 | Рис. 5 — чувствительность объёма и Score к температуре |
| R2-7, R2-11 | Test RMSE / R² / MAE (80:20) и 5-fold CV R² ± std; для реальных данных — `TimeSeriesSplit` |

## Переменные

| Вход | Описание | Диапазон |
|---|---|---|
| x1_syre | сырьё, м³/ч | 45–80 |
| x2_davlenie | давление, кг/см² | 20–35 |
| x3_temperatura | температура, °C | 300–343 |
| x4_skorost | объёмная скорость подачи, ч⁻¹ | 0.5–5 |
| x5_vsg | ВСГ, H₂/УВ, нм³ | 200–500 |

| Выход | Описание |
|---|---|
| y1_obyem | объём гидрогенизата, м³/ч |
| mu1_nepredelnye | степень гидрирования непредельных |
| mu2_sera | степень обессеривания (HDS) |
| mu3_kisloty | степень удаления кислых соединений |

Критерий качества: `Score = 0.35·μ1 + 0.40·μ2 + 0.25·μ3`, порог `Score ≥ 0.90`.

## Структура

```
generate_data.py    # 1. синтетический датасет (3000 строк): баланс выхода + кинетика Аррениуса
train_model.py      # 2. 4 модели XGBoost (y1, μ1, μ2, μ3), 80:20, RMSE/R²/MAE
validate_model.py   # 3. 5-fold CV (R² ± std), сверка суррогата с генератором
optimize.py         # 4. Eq. 16, таблица 1 на общей модели, Рис. 5, проверка утечки
compare_models.py   # сравнение 8 алгоритмов (LR, Ridge, KNN, RF, GB, XGBoost, LightGBM, MLP)
data/               # датасет и таблицы результатов
plots/              # parity, feature importance, model comparison, fig5
```

## Быстрый старт

```bash
pip install -r requirements.txt
python3 generate_data.py && python3 train_model.py && python3 validate_model.py && python3 optimize.py
```

Модели (`models/*.joblib`) не хранятся в репозитории — они создаются `train_model.py`.

## Результаты (XGBoost)

| Цель | Test RMSE | Test R² | Test MAE | 5-fold CV R² |
|---|---|---|---|---|
| y1_obyem | 2.031 | 0.962 | 1.593 | 0.961 ± 0.002 |
| mu1_nepredelnye | 0.023 | 0.987 | 0.019 | 0.987 ± 0.001 |
| mu2_sera | 0.024 | 0.988 | 0.019 | 0.988 ± 0.001 |
| mu3_kisloty | 0.023 | 0.988 | 0.018 | 0.987 ± 0.001 |

Рекомендованный режим (`optimize.py`): x1 = 79.9 м³/ч, x2 = 30.9 кг/см², x3 = 336.2 °C, x4 = 0.89 ч⁻¹, x5 = 226 нм³.
Проверка на генераторе: y1 = 79.5 < x1, μ = (0.87, 0.93, 0.91), Score = 0.905. Расхождение суррогат–генератор по y1 — 0.26 м³/ч (в пределах test RMSE).

## Переход на реальные данные завода

1. Замените `data/synthetic_dataset.csv` на реальный CSV с теми же именами колонок.
2. `python3 train_model.py && python3 validate_model.py && python3 optimize.py` (`generate_data.py` больше не нужен).
3. В `validate_model.py` используйте `cross_validation(df, time_ordered=True)` — временной (блочный) сплит.
4. В `generate_data.BOUNDS` сузьте границы до реально встречавшихся в исторических данных.

Подробности — в [HOW_TO_RUN.md](HOW_TO_RUN.md).
